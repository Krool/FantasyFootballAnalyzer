Privacy

Last updated 2026-11-10

Fantasy Football Analyzer is a free tool run by Krool World. There are no accounts on this site, no ads, and no database. This page lists what the site does with your data.

What is collected

Google Analytics. The site loads Google Analytics 4 to count visits. For each page it sends the page path, the page title, and any utm campaign tags from the link you followed. It also sends four events: a connect attempt, a league connected, a connect error (each with the platform name, and for errors a coarse class such as "not found" or "private league"), and a PDF export. League ids, usernames, tokens, and cookies are not sent, and the rest of the query string is dropped.

Google Analytics sets its own cookies on this domain (_ga and _ga_SXG8M67HPV) to tell one visit from another, and Google receives your IP address and browser details, as any web server does. There is no consent banner. A content blocker or the Google Analytics opt-out add-on stops it, and the site works the same without it.

Error reports. When the app hits an error, it sends a report to Sentry: the error message, the stack trace, your browser and operating system version, the page path, and the last few actions in the app (page changes, clicks, request URLs). Before sending, the app strips query strings, tokens, cookies, GUIDs, and any number of seven or more digits, which covers league ids. The app turns off Sentry's option to attach IP addresses and cookies. There is no session replay and no performance tracing. The stripping is automatic and pattern based.

League logins

The site never sees your Sleeper, ESPN, or Yahoo password.

  • Sleeper: no login. You type a username or league id and your browser calls Sleeper's public API directly.
  • ESPN, public league: your browser calls ESPN's API directly with the league id.
  • ESPN, private league: you paste your espn_s2 and SWID cookies. Those two values give access to your ESPN fantasy account, so the app keeps them only in this tab's session storage, which the browser clears when the tab closes. Each request sends them as headers to a proxy function this site runs on Vercel. The function forwards the request to ESPN and returns the answer. It does not store or log the cookies.
  • Yahoo: you sign in on Yahoo's own page. Yahoo sends a one-time code to a function this site runs on Vercel, which exchanges it for an access token and a refresh token and hands both to your browser in the part of the address after the #, which browsers do not send to servers. The app saves them in local storage and leaves that address. Later requests to Yahoo pass through the site's proxy function with the access token in a header, and the refresh token is sent to a second function when a new access token is needed. The functions keep nothing; on a failure they log the HTTP status code only.

The Yahoo login stays on this device until you press the Y! button to disconnect or clear the site's data. You can also remove the app's access from your Yahoo account settings.

Stored in your browser

The site keeps no server-side copy of anything below. Tokens and cookies leave your device only as described under League logins.

  • Local storage: the Yahoo access and refresh tokens; how you last connected (platform, league id, ESPN season, Sleeper username and user id) so the form is prefilled next time; cached copies of leagues you loaded (finished seasons for up to 30 days, live seasons for less) and of Yahoo league history; Draft Room sessions, presets, and your queue; target and avoid lists; cached Yahoo auction values; the sound on or off setting.
  • Session storage, cleared when the tab closes: ESPN cookies, guest mode settings, the one-time value that checks a Yahoo login returned to the tab that started it, and a marker that stops reload loops after a site update.

Clearing this site's data in your browser removes all of it.

Servers and other companies

  • GitHub Pages hosts the site. GitHub receives your IP address when pages load.
  • Vercel hosts the proxy functions. Vercel keeps standard request logs: IP address, time, and the request address, which for ESPN includes the league id and season and for Yahoo the league or team being read. This site has no database behind them.
  • Sleeper, ESPN, and Yahoo receive the requests for your league data.
  • Team logos load from ESPN's image host (a.espncdn.com) and player photos from Sleeper's (sleepercdn.com), so those hosts see your IP address.
  • Google Analytics and Sentry, as described above.

Fonts are served from this site. There are no ad networks. Nothing is sold or shared beyond the services listed here.

Share links

While a league is loaded, the address bar carries the platform and league id so the link can be shared. It never carries cookies or tokens. Anyone with a link to a Sleeper league or a public ESPN league can load that league, the same data those platforms' public APIs already return for the id.
